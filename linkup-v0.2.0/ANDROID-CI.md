# Android CI — LinkUp v0.2.0

Распаковать архив. Содержимое папки linkup-v0.2.0 (включая скрытую .github) поместить в корень своего приватного GitHub-репозитория. В Actions выбрать LinkUp Android CI → Run workflow. При успешном завершении скачать LinkUp-Android-debug из Artifacts. При падении — Android-diagnostics и лог задания. Сборка также стартует при изменениях Android/UI/тестов.

CI запускает существующие JS-тесты, сборку, Android Lint и два инструментальных smoke-теста на API 35: локальный интерфейс и нативный мост, переход в активность, импорт текста через системный Share. Это не проверка реального GPS, фонового поведения OEM или облака. Используются только тестовые данные, аккаунты Supabase/Drive не нужны. Не добавлять личные токены/данные в репозиторий.

Внимание: debug APK подписывается временным ключом runner. Для обновлений поверх ранее установленной версии необходим постоянный ключ подписи, хранящийся вне репозитория (например, в GitHub Actions Secrets); данная конфигурация его ещё не создаёт. Удаление установленной версии может стереть её локальные данные. CI не был запущен в среде ChatGPT из-за отсутствия SDK, Gradle и доступа к сети.

## Регрессии мобильного интерфейса

Активный workflow находится в корне репозитория по пути `.github/workflows/android.yml`. На одноразовом эмуляторе Android API 35 задачу можно повторить из каталога `linkup-v0.2.0/android`:

```sh
gradle :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
bash ../tools/test-android-mobile.sh
bash ../tools/test-android-upgrade.sh
```

Мобильный сценарий переключает эмуляцию выреза, жестовую и трёхкнопочную навигацию. Тесты проверяют клавиатуру и доступность элементов управления в обеих ориентациях, сохранение открытой формы, черновика, вложения и запроса после поворота, а также возврат из шторки уведомлений. Подписанное обновление запускается с одноразовым ключом и синтетическими данными. Оба сценария переустанавливают приложение на тестовом эмуляторе.

Артефакт `Android-diagnostics` содержит XML-результаты и каталог `android/app/build/mobile-diagnostics` со снимками `before`, `gesture` и `three-button`. Проверки физического экрана и клавиатур конкретных производителей требуют отдельного прогона.
