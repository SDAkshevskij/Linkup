# Roadmap

TASKS.md is the source of priority and acceptance criteria.

1. P0-A restores local Activity collection and verifies actual OS events on Android and X11. P0-B contains legacy plaintext exposure. P0-C diagnoses Android Supabase connectivity and validates it on a physical device with disposable credentials.
2. P1 defines the common end-to-end channel and release gates. The separate local HeliBoard keyboard is independent of cloud security. Both are deferred in the current work.
3. P2 covers automatic clipboard and background synchronization after their security gates, and the larger Activity presentation redesign.
4. The Android mobile fixes and signed-upgrade workflow are already merged. Maintain their regression coverage. v0.2.1 is published. Further production publication requires owner approval and the applicable security gates.
