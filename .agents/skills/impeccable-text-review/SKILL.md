# Impeccable text review — LinkUp adaptation

This local wrapper is not the full Impeccable tool. It uses selected upstream text references under Apache-2.0, with provenance in UPSTREAM.md. No launcher, binary, hooks, remote service, scripts, or automatic asset download are installed or permitted.

1. Read PRODUCT_QUALITY.md and the actual user brief. Identify the product's key action and visual focal point; compare two materially different concepts for substantial redesigns.
2. Inspect real rendered Android and Linux screens before editing if available. Use existing project screenshot and instrumentation tools. Review the current implementation rather than assuming a browser preview represents WebView/Qt.
3. Read reference/bolder.md when amplifying existing UI, and reference/craft-floor.md before final visual review. Ignore references to unavailable upstream launchers, font downloads or other Impeccable commands; perform those checks manually using authorized local tooling. Follow LinkUp's own design identity over generic defaults.
4. Evaluate hierarchy, originality, density, typography, interaction, contrast, focus, touch targets, system bars, scrollbars, long content, keyboard, reduced motion and responsive layouts. Review loading, empty, denied, offline and recovery states.
5. Produce concise findings grounded in screenshots; fix and re-render. Compare the before/after result. If screenshots are unavailable, state the gap rather than claiming visual verification.
6. Do not fetch fonts, external assets or dependencies without the project's licensing/security process. Do not replace app logic or change scope solely for aesthetics.
